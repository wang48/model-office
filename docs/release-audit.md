- 优化空状态、搜索无结果提示、字号、对比度及按钮区域。

- DeepSeek 为骨骼 VRM；Claude / GPT / Gemini 为真实 GLB 网格及形态键动画。四者均在 Magpie 中加载成功。
- 三个 GLB 已验证来源 ZIP 哈希、结构、形态键及实际顶点位移。
- 自动测试覆盖暂停、异步替换原图、加载失败回退、移除后释放资源，以及移除过程中异步加载不会复活角色。
- 未变化的会话不重建列表；隐藏场景停止 GPU 渲染。实际宿主验证过 13 个会话；未进行量化 FPS、显存或长期压力基准测试。
